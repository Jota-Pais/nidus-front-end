# Nidus — front-end

Interface web do **Nidus**, sistema de gestão de produção e manutenção de
roedores do **CPMR/UFSC** (Centro de Produção e Manutenção de Roedores da
Universidade Federal de Santa Catarina).

Projeto Integrador: Sistema Web — SATC, Engenharia de Software, fase 4, 2026.2.

## O que este repositório abriga

As telas do sistema. Nenhuma regra de negócio: cálculo de prazo, varredura por
idade, validação de cruzamento e alocação ficam no back-end.

Telas previstas:

- Login
- Grid de estantes — as duas faces lado a lado, um card por caixa
- Ficha do slot — modal, aberta de qualquer card
- Kanban de reprodução — raias de rato e camundongo, 5 colunas
- Solicitação de animais
- Análise da solicitação, com as sugestões do motor de varredura
- Registros do técnico: nascimento, eutanásia de seleção e desmame
